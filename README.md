## SQL Injection Demo Project (OWASP Top 10)

1. Built a vulnerable PHP login page
2. Demonstrated SQL Injection attack
3. Fixed the vulnerability using prepared statements
4. Used MySQL role-based access control

## Tools:
- Kali Linux
- Apache
- MySQL
- PHP

## OWASP Top 10:
- A03: Injection

## Description
This project demonstrates SQL Injection vulnerability and its prevention
using prepared statements in PHP and MySQL.

## Features
- Vulnerable login (SQL Injection works)
- Secure login (Prepared Statements)
- OWASP Top 10 concept
